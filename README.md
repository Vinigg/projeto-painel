# 🦎 Camaleão Multilingue

**Um painel de propaganda inteligente que se adapta automaticamente ao idioma do usuário**

## 📋 Sobre o Projeto

O **Camaleão Multilingue** é um sistema interativo de exibição de propagandas que identifica o idioma falado pelo usuário e exibe conteúdo personalizado automaticamente. Assim como um camaleão muda de cor para se adaptar ao ambiente, nosso painel "muda de idioma" para se comunicar eficazmente com cada pessoa.

### 🎯 Funcionalidade Principal
- **Detecta** a aproximação de pessoas através de sensor ultrassônico
- **Solicita** que o usuário fale por alguns segundos
- **Identifica** automaticamente o idioma falado
- **Exibe** propaganda no idioma correspondente
- **Personaliza** a experiência para cada visitante

- **Python** + Reconhecimento de Voz

- **Pygame** para exibição de conteúdo
- **Processamento de Áudio** em tempo real
